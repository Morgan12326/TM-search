# 数据结构

本文只描述文件职责，不复制实际语料内容。完整数据保存在本地 `data/`，默认不进入版本控制。

| 文件 | 作用 |
|---|---|
| `corpus.txt` | 中文正文语料，按偏移索引引用 |
| `offsets.json` | 正文块与语料偏移、文档编号的对应关系 |
| `entries.json` | 文档、词条、问答、访谈和分类元数据 |
| `story_blocks.json` | 可检索的中文剧情块 |
| `jp_blocks.json` | 可检索的日文块 |
| `story.json` | 剧情目录、路线、章节和导航结构 |
| `fgo_story.json` | FGO 官方剧本结构 |
| `official_interviews.json` | 官方问答和访谈索引 |
| `occurrence_locations.json` | 搜索结果到阅读器位置的映射 |
| `occurrence_exclusions.json` | 不参与位置索引的排除记录 |
| `occurrence_source_manifest.json` | 来源模式和合并状态清单 |
| `aliases.json` | 查询别名 |
| `alias_targets.json` | 别名目标 |
| `alias_notes.json` | 别名说明 |
| `query_rewrites.json` | 查询重写规则 |
| `suggest_overrides.json` | 联想词覆盖 |
| `vocab.json` | 联想词表 |
| `terms.json` | 术语辅助表 |
| `related.json` | 相关词条关系 |
| `kara_dict_cn.json` | 空之境界词典辅助数据 |
| `tmdict_profiles.json` | 词条归属和分类画像 |
| `tmdict_terms.json` | 词典来源词条 |
| `tsukihime_r.json` | 月姬 R 辅助数据 |
| `fex_fexl_glossary.json` | EXTELLA 系列辞典 |
| `fex_fexl_story_outline.json` | EXTELLA 系列剧情目录 |
| `fsn_fha_remastered_outline.json` | FSN/FHA 重制版剧情目录 |
| `name_aliases.json` | 人名别名 |
| `name_placeholders.json` | 人名占位规则 |
| `variant_stats.json` | 变体统计 |
| `zh_recovered_blocks.json` | 从日文块恢复的中文块索引 |

## 依赖方向

- `corpus.txt`、`offsets.json` 和 `entries.json` 是搜索基础。
- `story_blocks.json`、`jp_blocks.json` 和位置索引依赖基础语料。
- `story.json`、官方剧本和访谈索引依赖文档元数据。
- `tools/rebuild_source_data.py` 和 `tools/rebuild_occurrence_index.py` 负责主要派生关系。

详细执行顺序见 [维护指南](维护指南.md)。
